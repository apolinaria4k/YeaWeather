**YeaWeather**

Погодное приложение с минималистичным дизайном и расширенным прогнозом

**О проекте**

YeaWeather — это веб-приложение для отображения текущей погоды и прогноза на завтра в любом городе мира. Приложение использует WeatherAPI.com для получения актуальных данных о погоде и предоставляет удобный интерфейс с возможностью поиска городов, переключения между сегодняшним и завтрашним прогнозом, а также сохранением последнего выбранного города в локальном хранилище.

**Что было реализовано**

✅ Получение текущей погоды (температура, описание, скорость ветра, влажность, давление)

✅ Прогноз на завтра с 7 метриками погоды

✅ Поиск города с сохранением в localStorage

✅ Переключение между Today/Tomorrow с активным состоянием

✅ Адаптивная вёрстка с двумя колонками

✅ Day/Night режим (класс .is-day)

✅ Динамические иконки погоды

✅ Обработка ошибок с выводом сообщений пользователю

✅ Валидация ввода (trim, проверка на пустоту)

✅ Поддержка клавиши Enter для отправки запроса

**Технологии**

 - HTML5 — семантическая структура
 - CSS3 — кастомные стили, Flexbox, анимации
 - JavaScript (ES6+) — асинхронные запросы, работа с DOM, управление состоянием
 - WeatherAPI.com — источник данных о погоде
 - Google Fonts (Quicksand) — шрифт для интерфейса

**Основные функции**

 - fetchData(day) — универсальная функция для получения данных (Today/Tomorrow)
 - fetchToday(city) — запрос текущей погоды
 - fetchTomorrow(city) — запрос прогноза на завтра
 - updateStore(...) — обновление состояния приложения
 - renderComponent() — рендеринг UI на основе store
 - getImage(description) — маппинг описания погоды на иконку

**Обработчики событий**

 - handleFocus — очистка placeholder при фокусе на input
 - handleClick — поиск города по клику на кнопку или blur
 - handleKeyDown — отправка запроса по клавише Enter
 - handleForecastClick — переключение между Today/Tomorrow
